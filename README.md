# Pequenos Aprendizados em Programação

Este repositório reúne pequenos exercícios e projetos desenvolvidos durante meu processo de aprendizado em programação. O objetivo é praticar lógica de programação, compreender conceitos fundamentais e evoluir gradualmente através de desafios simples.

Aqui você encontrará códigos curtos e experimentos feitos em diferentes linguagens de programação, explorando conceitos como entrada de dados, estruturas condicionais, laços de repetição, operações matemáticas e resolução de problemas.

Cada arquivo representa um pequeno passo no meu desenvolvimento como programador. Este espaço funciona como um registro da minha evolução, onde pratico, erro, corrijo e continuo aprendendo.

## Objetivo

- Praticar lógica de programação  
- Aprender os fundamentos de diferentes linguagens  
- Desenvolver raciocínio computacional  
- Registrar minha evolução como desenvolvedor

## Linguagens utilizadas

- Python  
- Java  
- JavaScript  
- C  
- C++  

Este repositório representa minha jornada de aprendizado e desenvolvimento na área de tecnologia.
